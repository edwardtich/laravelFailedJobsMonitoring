# История изменений

## Не выпущено

### Добавлено

- Опция `filament.register_in_main_navigation`: регистрирует страницу из кластера в общем меню, для панелей, где подменю кластера скрыто, а его пункты выводятся под родительским пунктом. Раньше такая страница была доступна только по прямой ссылке.

## 2.1.0 - 2026-10-30

### Изменено

- `authorization.permissions.retry` / `delete` со значением `null` запрещают действие: retry и delete доступны только при явно настроенном и выданном permission.
- Страница задачи больше не показывает raw payload, сериализованную команду и raw exception.
- Удален `authorization.permissions.view_sensitive_payload`. Текст ошибки без маскирования и поиск по полному тексту доступны тем, кто может делать retry или delete.
- Пользователи без `retry` и `delete` видят текст ошибки с замаскированным SQL (`(Connection: ..., SQL: ...)`) и значениями `Duplicate entry`, без файла и строки, и ищут только по `uuid` и началу класса исключения; подсказка в поле поиска это отражает.
- `ui.retry_max_ids` по умолчанию 50: массовый retry выполняется синхронно в HTTP-запросе и должен укладываться в таймаут. Страница Filament отклоняет выбор больше лимита, а не перезапускает молча только первые задачи.
- Страница Filament: если настроен permission страницы (`filament.permission` или Shield) или `authorization.permissions.view`, доступ дает только он; `filament.roles` — запасной вариант для проектов без permissions.

### Добавлено

- Команда `failed-jobs-manager:permissions`: создает настроенные permissions через spatie/laravel-permission.
- Подтверждение перед перезапуском задачи и выбранных задач на странице Filament и в standalone UI.

## 2.0.0 - 2026-10-07

### Ломающие изменения

- Требуется PHP 8.3+ и Laravel 12 или 13; для Filament-страницы — Filament 4 или 5. Laravel 11 больше не поддерживается.
- Standalone UI закрыт вне окружения `local`, пока не настроен gate `viewFailedJobsManager` или `authorization.permissions.view`. Раньше любой авторизованный пользователь мог смотреть, перезапускать и удалять failed jobs.
- Поиск по `payload` доступен только с правом `view_sensitive_payload`; остальные ищут по `uuid` и `exception`.
- `retry_key = auto` теперь определяется по `queue.failed.driver` (`uuid` для `database-uuids`, иначе `id`).
- `table` / `connection` по умолчанию берутся из `queue.failed.table` / `queue.failed.database`.
- Списки в опубликованном конфиге (`middleware`, `roles`) заменяют значения пакета целиком, а не сливаются по индексам.

### Добавлено

- Отдельные права на просмотр, retry, удаление и просмотр чувствительного payload.
- Audit-события `FailedJobsRetried` и `FailedJobDeleted`.
- Cache lock на каждую задачу при retry — защита от повторной отправки при двойном клике или параллельной работе операторов.
- Опции `ui.retry_max_ids`, `ui.retry_lock_seconds`, `ui.queues_cache_ttl`.
- Тесты (Testbench) для Laravel 12/13 и Filament 4/5.

### Исправлено

- Ненайденные задачи считались успешно перезапущенными.
- Поддержаны legacy-таблицы `failed_jobs` без колонки `uuid` (поиск по uuid пропускается, uuid берётся из payload).
- Ошибки очереди при retry/удалении давали HTTP 500; теперь они логируются и показываются как неудачная операция.
- Текст подтверждения удаления вставлялся в inline JavaScript без JS-экранирования.
- `%` и `_` в поиске работали как wildcard в `LIKE`.
- Нечисловые ID доходили до БД (500 на PostgreSQL); роуты теперь принимают только числовые ID.
- Кнопки retry/удаления показывались пользователям без соответствующих прав.
- Пункт Filament-навигации дублировался в основном меню при заданном cluster.

### Производительность

- Сортировка по первичному ключу вместо неиндексированного `failed_at`.
- Убран лишний `COUNT(*)` для отфильтрованного списка и повторный запрос пагинации при выборе в Filament.
- Список очередей кешируется; разбор payload/exception мемоизируется; фильтр по дате — полуоткрытый интервал.
- Валидация bulk retry больше не использует O(n²) правило `distinct`.

## 1.1.0 - 2026-06-26

### Добавлено

- Добавлена опциональная страница Filament для управления failed jobs.
- Добавлено удаление одной failed job через Laravel `queue:forget`.
- Добавлен массовый повтор выбранных failed jobs.
- Добавлены русские и английские переводы.
- Добавлена настройка ключа для `queue:retry` и `queue:forget`.
- Добавлены читаемые сводки payload и exception.

### Изменено

- Улучшен standalone UI: фильтры, пагинация, переведенные подписи и вывод ошибок валидации.
- Улучшен Filament UI: ручные controls пагинации и более строгая нормализация фильтров.
- Улучшено слияние config, чтобы вложенные настройки пакета всегда были доступны.
- Расширена русская и английская документация по установке, конфигурации, Filament, безопасности и действиям очередей.

### Исправлено

- Исправлен сломанный вывод стрелок пагинации Filament заменой стандартных pagination links на явные controls.
- Исправлен массовый retry: отсутствующие выбранные jobs больше не передаются в `queue:retry`.

## 1.0.0 - 2026-06-26

### Добавлено

- Первый standalone Laravel UI для просмотра и повтора failed jobs.
